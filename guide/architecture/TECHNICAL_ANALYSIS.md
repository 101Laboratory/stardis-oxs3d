# Stardis GPU迁移项目 - 技术分析报告

## 项目概述分析

### 1. 项目基本信息
- **项目名称**: Stardis (红外渲染引擎)
- **版本**: 0.16.2
- **许可证**: GNU GPL v3
- **开发公司**: Méso|Star (contact@meso-star.com)
- **源代码语言**: C语言 (C89标准)
- **构建系统**: Makefile + config.mk
- **并行支持**: OpenMP + MPI (可选)

### 2. 项目架构分析

#### 2.1 核心模块划分
```
Stardis架构:
├── 核心求解器 (sdis_solve.c)
│   ├── 探头求解器 (probe solver)
│   ├── 边界求解器 (boundary solver)
│   ├── 介质求解器 (medium solver)
│   └── 格林函数求解 (green function)
├── 蒙特卡洛实现 (sdis_realisation.c)
│   ├── 射线跟踪 (ray tracing)
│   ├── 辐射路径采样 (radiative path sampling)
│   └── 热耦合路径采样 (coupled path sampling)
├── 热路径管理 (sdis_heat_path.c)
│   ├── 热顶点注册
│   ├── 热路径计算
│   └── 边界处理
├── 数据结构
│   ├── 场景管理 (sdis_scene.c)
│   ├── 相机系统 (sdis_camera.c)
│   ├── 介质属性 (sdis_medium.c)
│   └── 辐射环境 (sdis_radiative_env.c)
└── 辅助模块
    ├── 日志系统 (sdis_log.c)
    ├── 设备管理 (sdis_device.c)
    └── 随机数生成 (依赖ssp库)
```

#### 2.2 关键技术特征
1. **双精度计算**: 使用double类型进行物理计算
2. **蒙特卡洛方法**: 基于随机采样的辐射传输求解
3. **几何处理**: 支持2D/3D场景 (通过宏切换)
4. **热物理模型**: 包含热传导、辐射、对流耦合
5. **并行计算**: OpenMP多线程 + MPI分布式

### 3. 算法分析

#### 3.1 核心算法流程
```c
// 简化算法流程
1. 场景加载和初始化
2. 热路径预处理
3. 蒙特卡洛采样循环:
   while(采样数 < N) {
     a. 生成随机射线
     b. 跟踪辐射路径
     c. 计算热耦合
     d. 累加权重
   }
4. 结果后处理和输出
```

#### 3.2 计算密集型部分 (GPU迁移重点)
1. **射线跟踪循环** (sdis_realisation.c):
   - 几何求交计算
   - 方向采样和传播
   - 路径权重计算

2. **蒙特卡洛采样**:
   - 大规模独立样本生成
   - 随机数生成消耗
   - 并行采样累加

3. **热路径计算**:
   - 热顶点处理
   - 边界条件计算
   - 温度场求解

4. **格林函数计算**:
   - 矩阵运算
   - 积分计算
   - 边界值问题求解

### 4. 数据结构和内存模式

#### 4.1 关键数据结构
```c
// 主要数据结构 (来自sdis.h)
struct sdis_scene;          // 场景容器
struct sdis_camera;         // 相机和观测
struct sdis_medium;         // 介质属性
struct sdis_heat_path;      // 热路径
struct sdis_green_function; // 格林函数
struct sdis_estimator;      // 结果估计器
```

#### 4.2 内存访问模式
- **AoS模式**: 结构体数组 (适合CPU缓存)
- **随机访问**: 几何求交需要随机内存访问
- **大规模数据**: 场景几何、材质属性、采样结果

#### 4.3 GPU迁移适应性分析
| 数据结构 | CPU适应性 | GPU适应性 | 迁移策略 |
|----------|-----------|-----------|----------|
| 场景几何 | 高 | 中 | 转换为GPU友好格式 |
| 热路径数据 | 高 | 低 | 重新设计为并行结构 |
| 采样结果 | 高 | 高 | 直接并行累加 |
| 随机数序列 | 高 | 高 | GPU随机数生成 |

### 5. 第三方依赖分析

#### 5.1 必需依赖库
```
rsys (v0.14)      - 运行时系统库
s2d (v0.7)        - 2D几何库
s3d (v0.10)       - 3D几何库  
senc2d (v0.5)     - 2D场景编码

```

#### 5.2 依赖迁移策略
1. **直接替换**: 随机数生成库 (ssp) → CUDA/HIP随机数
2. **重新实现**: 几何库功能 → DirectX几何处理
3. **封装适配**: 运行时系统功能 → C++标准库
4. **功能合并**: 场景编码功能整合到渲染管道

### 7. GPU迁移技术挑战

#### 7.1 算法层面挑战
1. **随机性管理**: GPU上的随机数生成和同步
2. **递归算法**: 蒙特卡洛路径跟踪的递归实现 → 迭代化
3. **动态数据结构**: 热路径的动态增长 → 预分配固定大小
4. **精度要求**: 双精度计算的GPU性能优化

#### 7.2 架构层面挑战
1. **数据布局**: AoS到SoA转换的GPU优化
2. **内存层次**: GPU内存带宽和延迟优化
3. **计算管道**: 异步计算和图形管道的协调
4. **资源管理**: DX12显式资源生命周期管理

#### 7.3 验证层面挑战
1. **结果一致性**: GPU/CPU双精度结果对比
2. **随机性验证**: 不同随机数序列的结果统计一致性
3. **性能验证**: GPU加速比的准确测量
4. **边界情况**: 极端场景下的正确性验证

### 8. 技术选型建议

#### 8.1 DirectX 12特性利用
1. **计算着色器**: 核心算法实现
2. **异步计算**: 多队列并行执行
3. **光追加速**: DXR 1.1 (可选，未来扩展)
4. **Mesh Shader**: 几何处理优化 (RTX 40系列)
5. **Shader Model 6.6**: 最新特性支持

#### 8.2 双精度计算策略
1. **原生双精度**: RTX 4090双精度支持
2. **混合精度**: FP16加速 + FP64精度关键部分
3. **误差控制**: 精度阈值和容错机制
4. **验证机制**: 逐像素对比验证框架

#### 8.3 内存管理策略
1. **上传堆**: 主机到设备数据传输
2. **默认堆**: 设备端数据存储
3. **读取回堆**: 结果回读到主机
4. **自定义分配器**: D3D12MA内存管理

2. **算法并行化**: 递归算法的GPU适配
