## 1. 序列模式实现状态对比

### 1.1 序列1：几何体注册（Geometry Registration）

**文档描述**：`rtcNewGeometry` → `rtcSetGeometry*` → `rtcAttachGeometry` 连续调用

#### 实现状态：✅ **完全实现**

**Embree实现位置**：
- `embree_impl/embree_unified_renderer.cpp`：
  - **三角形网格**（第207-218行）：
    ```cpp
    geometry_ = rtcNewGeometry(device_, RTC_GEOMETRY_TYPE_TRIANGLE);
    rtcSetSharedGeometryBuffer(...);  // 顶点缓冲区
    rtcSetSharedGeometryBuffer(...);  // 索引缓冲区  
    rtcCommitGeometry(geometry_);
    rtcAttachGeometry(scene_, geometry_);
    ```
  
  - **球体（自定义几何体）**（第228-237行）：
    ```cpp
    geometry_ = rtcNewGeometry(device_, RTC_GEOMETRY_TYPE_USER);
    rtcSetGeometryUserPrimitiveCount(geometry_, numSpheres_);
    rtcSetGeometryUserData(geometry_, (void*)this);
    rtcSetGeometryBoundsFunction(geometry_, sphereBoundsFunc, nullptr);
    rtcSetGeometryIntersectFunction(geometry_, sphereIntersectFunc);
    rtcCommitGeometry(geometry_);
    rtcAttachGeometry(scene_, geometry_);
    ```
  
  - **实例**（第254-261行）：
    ```cpp
    RTCGeometry instanceGeom = rtcNewGeometry(device_, RTC_GEOMETRY_TYPE_INSTANCE);
    rtcSetGeometryInstancedScene(instanceGeom, baseScene_);
    rtcSetGeometryTransform(instanceGeom, 0, RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR, inst.transform);
    rtcSetGeometryUserData(instanceGeom, (void*)(intptr_t)i);
    rtcCommitGeometry(instanceGeom);
    rtcAttachGeometry(scene_, instanceGeom);
    ```

**cuBQL对应实现**：
- **打包函数策略**：`buildTriangleBVH()`, `buildSphereBVH()`, `buildInstanceBVH()`
- **API映射**：单个Embree序列 → 单个cuBQL构建函数
- **优势**：减少CPU-GPU同步，批量处理数据
