🔧 核心新功能
===============================================================================

1. validate_library_sources(sources_var)
   - 检测测试文件混入库源
   - 编译时报错，清晰提示

2. generate_namespace_headers(TARGET, NAMESPACE, HEADERS)
   - 统一生成 star/rsys 命名空间
   - 减少 17 行/模块重复代码
   - 自动配置 include 路径

3. glob_library_sources(out_var)
   - 安全的源文件 glob
   - 自动排除 test_*.c

4. filter_test_headers(out_var, ...)
   - 过滤测试头文件

5. load_modules(module_list, category_name)
   - Workspace 数组+循环加载
   - 支持 REQUIRED/OPTIONAL

6. validate_cmake_modules.sh
   - 6 类反模式检测
   - 彩色输出
   - CI/CD 就绪

🚀 使用指南
===============================================================================

新项目:
  1. 复制 HelperFunctions.cmake 到 cmake/
  2. 使用 CMakeLists_workspace.txt 作为模板
  3. 使用 CMakeLists_module.txt 作为模块模板
  4. 运行 validate_cmake_modules.sh 验证

现有项目迁移:
  1. 更新 HelperFunctions.cmake
  2. 逐个模块添加 validate_library_sources()
  3. 逐个模块替换命名空间生成代码
  4. 运行验证脚本
  5. 可选：迁移 Workspace 到数组+循环

详见: templates/cmake/v1.1/README.md
