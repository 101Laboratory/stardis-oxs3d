**关联清单**: [../numerical_correctness_test_checklist.md](../numerical_correctness_test_checklist.md)

**物理领域**: 非凸几何、自定义路径采样、极限边界条件  
**共同容差**: 视具体测试而定

---

## 物理总论

鲁棒性测试不关注新物理，而是验证求解器在**边界和病态条件**下是否仍能给出正确结果。这类测试对 GPU 迁移尤为重要：

1. **非凸几何**: cuBQL BVH 遍历在非凸几何体（如超形状 superquadric）上可能产生多次交点
2. **WoS (Walk on Spheres)** 与 **DS (Direct Simulation)**: 两种 MC 路径采样策略在复杂几何上行为不同
3. **空腔极限 (enclosure limit)**: 内嵌空腔趋于无穷大时的退化行为

---

## WF-G1：非凸超形状随机游走（对标 `test_sdis_solid_random_walk_robustness`）

### 物理场景

在超形状（superquadric）几何体内做随机游走。超形状的表面方程为：

$$\left|\frac{x}{a}\right|^{p} + \left|\frac{y}{b}\right|^{q} + \left|\frac{z}{c}\right|^{r} = 1$$

当 $p, q, r \ne 2$ 时几何体为非凸，MC 路径可能穿过同一面多次。

### 验证方法

使用三线性温度场（与 B5 相同）：

$$T(x,y,z) = a_x x + a_y y + a_z z + T_0$$

在此线性场下，MC 应精确恢复温度值（理论零方差）。如果结果偏离，说明几何计算（交点/法向量/BVH 遍历）有误。

### 双策略对比

| 策略 | 缩写 | 说明 |
|---|---|---|
| Direct Simulation | DS | 逐步模拟布朗运动，步长 $= \delta$ |
| Walk on Spheres | WoS | 跳跃到最近边界的球面上 |

CPU 测试验证 DS 和 WoS 在超形状上给出一致结果。

### GPU Wavefront 适配

- **关键验证**: cuBQL BVH 对非凸几何的正确遍历
- **挑战**: 超形状三角网格化后三角形数量多，BVH 构建质量影响正确性
- **SPP**: 256
- **通过标准**: 失败率 ≤ 0.05%（与 CPU 同口径）
- **优先级**: P2

## WF-A7（鲁棒性维度）：内嵌球体作为 BVH 压力测试

### 与类别 A 的区别

在类别 A 中，WF-A7 验证物理正确性（球体不影响线性温度场）。在本类别中，重点是：

1. **多 BVH 节点遍历**: 球体 + 外部立方体产生嵌套 BVH
2. **光线多次穿越**: 射线必须正确穿过球体表面两次
3. **法向量一致性**: 球体内/外的法向量方向不能混淆

### GPU Wavefront 特有风险

- cuBQL 的 closest-hit 语义在多嵌套几何时的行为
- 三角化球面的法向量插值精度
- 从球体内部出发的射线自相交问题

### 测试操作

与 cat_A 中的 WF-A7 共享测试代码，但在本文档中强调其鲁棒性验证意义。

## WF-I3：空腔极限条件（对标 `test_sdis_enclosure_limit`）

### 物理场景

一个固体内部有空腔（enclosure），空腔壁面发射率 $\varepsilon = 1$。当空腔尺寸趋于零或趋于无穷大时：

| 极限 | 物理行为 | 预期 |
|---|---|---|
| 空腔 → 0 | 退化为纯导热 | 温度场应趋于无空腔解 |
| 空腔 → ∞ | 壁面间辐射可忽略 | 温度场应趋于绝热空腔解 |

### 验证方法

CPU 测试使用**精确相等**检验：在极限条件下，MC 估计值的方差应为零（因为所有随机游走路径都给出相同温度）。

```c
CHK(T.E == T_expected);  /* 精确相等，非 eq_eps */
```

### GPU Wavefront 适配

- **优先级**: P3
- **SPP**: 128（零方差场景不需高 SPP）
- **通过标准**: 精确相等或 1σ 内
- **验证重点**: Wavefront 批量处理不会在零方差场景引入伪随机噪声

## 类别 G 综合诊断流程

```
WF-A7 (嵌套球体) 通过?
  ├── 否 → BVH 多层遍历有问题
  │         检查: closest-hit 在嵌套几何上的行为
  │         检查: 自相交 epsilon 设置
  └── 是 → WF-G1 (超形状) 通过?
            ├── 否 → 非凸几何 BVH 有问题
            │         检查: 三角化质量
            │         检查: 法向量方向一致性
            └── 是 → WF-I3 (空腔极限) 通过?
                      ├── 否 → 退化条件处理有问题
                      │         检查: 零空腔/无穷空腔特殊路径
                      └── 是 → 鲁棒性验证完毕 ✓
```

### 类别 G 小结

| WF ID | 验证重点 | 失败暗示 |
|---|---|---|
| WF-G1 | 非凸几何 MC 路径 | BVH 遍历或交点计算对非凸体有误 |
| WF-A7 | 嵌套几何 BVH | 多层几何或自相交处理错误 |
| WF-I3 | 极限退化行为 | 边界条件在极端参数下的数值不稳定 |

**执行顺序**: WF-A7（P2）→ WF-G1（P2）→ WF-I3（P3）
