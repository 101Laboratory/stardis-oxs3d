# 类别 F：外部通量实验原理

**关联清单**: [../numerical_correctness_test_checklist.md](../numerical_correctness_test_checklist.md)  
**GPU 测试 ID**: WF-F1, WF-F2  
**物理领域**: 外部辐射源（太阳辐照）+ 反射面（漫射/镜面地面）  
**共同容差**: `eq_eps(T.E, ref, 3 * T.SE)`

---

## 物理总论

外部通量场景模拟太阳等远距球形辐射源对物体的加热效应。物体表面吸收太阳辐照后，通过对流冷却与自身辐射达到温度平衡。

关键物理量：
- **辐照度 (irradiance)** $E$ [W/m²]: 物体表面每单位面积接收的辐射能
- **视角选择 (view selection)**: 地面反射（漫射 Lambertian / 镜面 specular）改变物体接收的间接辐照

对于远距球形源，在距离 $d$ 处的辐照度：

$$E = \frac{P_{sun}}{4\pi d^2}$$

但由于考虑太阳盘张角和地面反射，实际到达物体表面的等效通量更加复杂。

## WF-F1：球形太阳源 + 墙体 + 地面反射（对标 `test_sdis_external_flux`）

### 物理场景

一面薄墙壁，受阳光照射，墙壁前有地面可反射阳光。

```
       ☀ 太阳 (仰角30°, 距1.5×10¹¹m)
       ↙ ↓ ↘ (直射 + 地面反射)
┌─────────────┐
│  Wall 墙体  │ ← 导热材料, ε=1, H_conv=10
│  探针 @ 中心 │
└─────────────┘
════════════════════ Ground 地面 (漫射/镜面)
```

### 参数

| 参数 | 值 | 单位 | 说明 |
|---|---|---|---|
| `T_FLUID` | 300.0 | K | 环境流体温度 |
| `T_REF` | 300.0 | K | 辐射参考温度 |

**墙体材料 (MEDIUM_PROP)**:

| 属性 | 值 | 单位 |
|---|---|---|
| $\rho$ | 1700 | kg/m³ |
| $c_p$ | 800 | J/(kg·K) |
| $\lambda$ | 1.15 | W/(m·K) |
| $\delta$ | 0.005 | m |

**太阳参数**:

| 参数 | 值 | 单位 |
|---|---|---|
| 功率 $P_{sun}$ | $3.845 \times 10^{26}$ | W |
| 半径 $R_{sun}$ | $6.5991756 \times 10^8$ | m |
| 仰角 | 30° | rad |
| 距离 $d$ | $1.5 \times 10^{11}$ | m |
| 位置 | $(\cos 30° \times d, \sin 30° \times d, 0)$ | m |

**几何**:

| 对象 | 2D 范围 | 3D 范围 |
|---|---|---|
| Wall (墙) | $(-0.1, 500) → (0, 1500)$ | $(-0.1, 500, -500) → (0, 1500, 500)$ |
| Ground (地面) | $(0, -1) → (10^{12}, 0)$ | $(0, -1, -10^6) → (10^{12}, 1, 10^6)$ |

**观测点**: $(-0.05, 1000, 0)$（墙体中心）

### 界面属性

| 界面 | 发射率 $\varepsilon$ | 对流 $H$ [W/(m²·K)] | 镜面分数 |
|---|---|---|---|
| Ground (漫射) | 0 | 0 | 0 |
| Ground (镜面) | 0 | 0 | 1 |
| Wall | 1 | 10 | — |

**辐射环境**: $T_{env} = 0$ K（太空背景），$T_{ref} = 300$ K

### 解析参考温度

| 地面类型 | N | 参考温度 [K] | 说明 |
|---|---|---|---|
| Lambertian（完全漫射, specular=0） | 10,000 | **375.88** | 地面漫射反射减少间接辐照 |
| Specular（完全镜面, specular=1） | 100,000 | **417.77** | 镜面反射增加间接辐照 |

温度差异 $\Delta T \approx 42$ K 反映了地面反射类型对墙体温度的显著影响。

### 物理解释

1. **太阳直射**: 太阳辐照以仰角 30° 照射墙体表面
2. **地面反射**: 
   - Lambertian: 入射光被均匀漫射到半球，只有部分到达墙体
   - Specular: 入射光按镜面反射，更多能量集中到墙体方向
3. **散热**: 墙体通过 $H = 10$ W/(m²·K) 对流冷却和 $\varepsilon = 1$ 辐射散热到 $T_{env} = 0$ K
4. **稳态平衡**: 吸收 = 对流散热 + 辐射散热

### GPU Wavefront 适配

- **挑战**: 外部源需要长距离光线追踪（$d = 1.5 \times 10^{11}$ m）
- **BVH**: 需要处理极端尺度差异（墙厚 0.1 m vs 太阳距离 $10^{11}$ m）
- **SPP**: 512（specular 需更高样本）
- **通过标准**: ≥95% 在 3σ 内
- **双测试**: Lambertian + Specular 分别验证

### 验证代码模式

```c
/* Lambertian ground */
double analytical_ref = 375.88;
CHK(eq_eps(analytical_ref, T.E, 3.0 * T.SE) == 1);

/* Specular ground */
double analytical_ref = 417.77;
CHK(eq_eps(analytical_ref, T.E, 3.0 * T.SE) == 1);
```

## WF-F2：外部源 + 漫射辐照度（对标 `test_sdis_external_flux_with_diffuse_radiance`）

### 物理场景

远距辐射源 + 各向同性漫射辐照背景。验证两种辐照路径的叠加正确性。

### 物理原理

漫射辐照度（diffuse radiance）$L_d$ [W/(m²·sr)] 各向均匀入射到物体表面：

$$E_{diffuse} = \pi L_d$$

与直射源叠加后，物体表面总入射通量 $= E_{direct} + E_{diffuse}$，稳态平衡由 Stefan-Boltzmann 定律决定。

### GPU Wavefront 适配

- **验证重点**: 源辐照 + 背景辐照的正确叠加
- **SPP**: 256
- **优先级**: P1
- **通过标准**: 3σ

## 类别 F 小结

| WF ID | 验证重点 | 失败暗示 |
|---|---|---|
| WF-F1 Lambertian | 太阳直射 + 漫射地面反射 | 外部源采样或漫射反射有误 |
| WF-F1 Specular | 太阳直射 + 镜面地面反射 | 镜面反射方向计算有误 |
| WF-F2 | 直射 + 漫射辐照叠加 | 多源辐照叠加逻辑有误 |

### 诊断策略

如果 Lambertian 正确但 Specular 不正确 → 镜面反射路径有 bug  
如果两者都偏高 → 散热（对流/辐射）计算偏低  
如果两者都偏低 → 太阳源采样或入射角计算有误

**执行顺序**: WF-F1 Lambertian → WF-F1 Specular → WF-F2
