# 类别 A：纯导热稳态实验原理

**关联清单**: [../numerical_correctness_test_checklist.md](../numerical_correctness_test_checklist.md)  
**GPU 测试 ID**: WF-A1, WF-A2, WF-A3, WF-A6, WF-A7  
**物理领域**: 稳态热传导（无辐射、无对流、无瞬态）  
**共同容差**: `eq_eps(T.E, ref, 3 * T.SE)` （3σ MC 标准误差）

---

## 物理总论

纯导热稳态问题满足 Laplace/Poisson 方程：

$$-\nabla \cdot (\lambda \nabla T) = P \quad \text{在} \; \Omega \; \text{中}$$

在一维均质情况下简化为：

$$-\lambda \frac{d^2T}{dx^2} = P$$

其中 $\lambda$ 为热导率 [W/(m·K)]，$P$ 为体积功率密度 [W/m³]。

蒙特卡洛求解器通过随机游走估计温度场：从探针位置出发，在固体内随机行走直到到达边界，用边界温度与路径上的源项贡献加权得到温度估计。稳态导热是最简单的物理场景，**如果此类测试不通过，所有更复杂的物理都不可信**。

## WF-A1：固定温度 + 固定通量（对标 `test_sdis_flux`）

### 物理场景

一维稳态导热：左面 ($x=0$) 固定温度 $T_0$，右面 ($x=1$) 固定热通量 $\Phi$。

```
     Φ (通量)         λ (导体)          T₀ (固定温度)
  ←─────────┤ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ├──────────→
  x=1                                 x=0
```

### 解析推导

由 $-\lambda \frac{d^2T}{dx^2} = 0$（无体积源），积分两次：

$$T(x) = c_1 x + c_2$$

边界条件：
- $T(0) = T_0 \implies c_2 = T_0$
- $-\lambda \frac{dT}{dx}\big|_{x=1} = \Phi \implies c_1 = -\Phi/\lambda$

$$\boxed{T(x) = T_0 + (1 - x) \cdot \frac{\Phi}{\lambda}}$$

### 参数

| 参数 | 值 | 单位 | 说明 |
|---|---|---|---|
| `T0` | 320 | K | $x=0$ 固定温度 |
| `PHI` | 10 | W/m² | $x=1$ 面施加通量 |
| `LAMBDA` | 0.1 | W/(m·K) | 热导率 |
| `N` | 10000 | — | MC 实现次数 |

### 解析参考值

在 $x$ 处：$T(x) = 320 + (1 - x) \times 10 / 0.1 = 320 + 100(1-x)$

| 位置 $x$ | 温度 [K] |
|---|---|
| 0.0 | 420 |
| 0.25 | 395 |
| 0.5 | 370 |
| 0.75 | 345 |
| 1.0 | 320 |

### GPU Wavefront 适配

- **API**: `sdis_solve_wavefront_probe(pos={x, 0.5, 0.5})` 或正交相机沿 X 轴采样
- **几何**: 单位立方体 (0,0,0)→(1,1,1)，12 三角形
- **覆盖**: 2D（正方形 4 线段）+ 3D（立方体 12 三角形）
- **SPP**: 256（GPU 可轻松达到低 SE）
- **通过标准**: ≥95% 探针在 3σ 内

### 验证代码模式

```c
/* 解析参考 */
double ref = T0 + (1.0 - pos_x) * PHI / LAMBDA;
/* 3σ 验证 */
CHK(eq_eps(T.E, ref, 3.0 * T.SE) == 1);
```

## WF-A2：体积功率 + 两面固定温度（对标 `test_sdis_volumic_power`）

### 物理场景

一维稳态导热：两面 ($x = \pm 1/2$) 固定温度 $T_0$，均匀体积功率 $P$。

```
  T₀ ├──── ▓▓▓  P (体积功率)  ▓▓▓ ────┤ T₀
  x=-1/2          x=0              x=+1/2
```

### 解析推导

由 $-\lambda \frac{d^2T}{dx^2} = P$，在 $x \in [-1/2, 1/2]$ 上积分：

$$T(x) = -\frac{P}{2\lambda} x^2 + c_1 x + c_2$$

对称性 → $c_1 = 0$；$T(\pm 1/2) = T_0$ → $c_2 = T_0 + P/(8\lambda)$

$$\boxed{T(x) = \frac{P}{2\lambda}\left(\frac{1}{4} - x^2\right) + T_0}$$

### 参数

| 参数 | 值 | 单位 |
|---|---|---|
| `T0` | 320 | K |
| `P0` | 10 | W/m³ |
| `LAMBDA` | 0.1 | W/(m·K) |
| `N` | 10000 | — |

### 解析参考值

$$T(0) = \frac{10}{0.2} \times 0.25 + 320 = 12.5 + 320 = 332.5 \text{ K}$$

| 位置 $x$ | 温度 [K] |
|---|---|
| 0 | 332.5 |
| ±0.25 | 329.375 |
| ±0.5 | 320 |

### GPU Wavefront 适配

- **API**: 正交相机对齐 X 轴，像素映射 $x \in [-0.5, 0.5]$
- **几何**: 单位立方体，表面设 $T_0 = 320$ K；体积功率 $P = 10$ W/m³
- **SPP**: 256
- **特点**: 抛物线分布，中心温度最高，验证体积源项是否正确累积

## WF-A3：双材料 + 接触热阻（对标 `test_sdis_contact_resistance`）

### 物理场景

两层材料（$\lambda_1, \lambda_2$）在 $x = x_0$ 处有接触热阻 $R$，两端固定温度。

```
  T₀=0 ├── λ₁ ──┤ R ├── λ₂ ──┤ T_L=100
  x=0          x₀=3         x=L=4
```

### 解析推导

接触面热阻使界面两侧有温度跳跃 $\Delta T = R \cdot q$，其中 $q$ 为通量：

$$q = \frac{T_L - T_0}{\frac{x_0}{\lambda_1} + R + \frac{L - x_0}{\lambda_2}}$$

左侧 ($0 \le x \le x_0$)：$T(x) = T_0 + \frac{q}{\lambda_1} x$

右侧 ($x_0 \le x \le L$)：$T(x) = T_L - \frac{q}{\lambda_2}(L - x)$

### 参数

| 参数 | 值 | 单位 |
|---|---|---|
| `T0` | 0 | K |
| `TL` | 100 | K |
| `LAMBDA1` | 0.1 | W/(m·K) |
| `LAMBDA2` | 0.2 | W/(m·K) |
| `L` | 4.0 | m |
| `X0` | 3.0 | m（界面位置）|
| `R` | $10^{U(-2,2)}$ | m²·K/W（随机扫描）|
| `N` | 10000 | — |

### 特殊之处

CPU 测试在对数尺度上扫描热阻：$R = 10^{U_i}$，$U_i \sim \text{Uniform}(-2, 2)$，覆盖 $R \in [0.01, 100]$。这验证了求解器对接触热阻参数变化的鲁棒性。

### GPU Wavefront 适配

- **挑战**: 需要支持多材料场景 + 接触热阻
- **建议**: 选取 $R \in \{0.01, 0.1, 1, 10, 100\}$ 固定值测试，避免随机扫描增加测试不确定性
- **SPP**: 256
- **通过标准**: 每个 $R$ 值，≥95% 探针在 3σ 内

## WF-A6：体积功率 + 对流边界条件（对标 `test_sdis_volumic_power4`）

### 物理场景

一维稳态导热：均匀体积功率 $P$，一面绝热（$y = -1/4$），另一面对流冷却（$y = +1/4$，换热系数 $H$，流体温度 $T_f$）。

```
  绝热 ├──── ▓▓▓  P (体积功率)  ▓▓▓ ────┤ H, T_f (对流)
  y=-1/4            y=0              y=+1/4
```

### 解析推导

$$-\lambda \frac{d^2T}{dy^2} = P$$

边界条件：
- $\frac{dT}{dy}\big|_{y=-1/4} = 0$（绝热）
- $-\lambda \frac{dT}{dy}\big|_{y=1/4} = H(T|_{y=1/4} - T_f)$（对流）

解：

$$T(y) = -\frac{P}{2\lambda} y^2 + T_f + \frac{P}{2H} + \frac{P}{8\lambda}$$

$$\boxed{T(0) = T_f + \frac{P}{2H} + \frac{P}{8\lambda} = 100 + \frac{10000}{100} + \frac{10000}{800} = 212.5 \text{ K}}$$

### 参数

| 参数 | 值 | 单位 |
|---|---|---|
| `Power` | 10000 | W/m³ |
| `H` | 50 | W/(m²·K) |
| `LAMBDA` | 100 | W/(m·K) |
| `Tf` | 100 | K |
| `N` | 100000 | — |

### GPU Wavefront 适配

- **注意**: CPU 用 100k 实现次数（高精度要求）
- **SPP**: 512（GPU 并行度可补偿）
- **关键验证**: 对流 Robin 边界条件 + 体积源的正确耦合

## WF-A7：内嵌球体同材料（对标 `test_sdis_solve_probe3`）

### 物理场景

立方体内部嵌入球体（$R = 0.25$），球体与外部材料热导率相同。前后两面施加不同温度，其余绝热。**球体不应影响温度场**，验证几何复杂度不引入伪影。

```
  T_front=300 ├── λ ── (○ 球体, λ) ── λ ──┤ T_back=350
```

### 参数

| 参数 | 值 | 单位 |
|---|---|---|
| `lambda` | 50 | W/(m·K) |
| `cp` | 2 | J/(kg·K) |
| `rho` | 25 | kg/m³ |
| `R_sphere` | 0.25 | m |
| `T_front` | 300 | K |
| `T_back` | 350 | K |
| `N` | 10000 | — |

### 解析参考

中心处（$x = 0.5$）：$T = (T_{front} + T_{back}) / 2 = 325$ K

线性温度分布：$T(x) = T_{front} + (T_{back} - T_{front}) \cdot x$

### GPU Wavefront 适配

- **关键验证**: 多固体域场景下 BVH 遍历的正确性
- **SPP**: 128（高热导率 → 低方差）
- **通过标准**: ≥95% 3σ
- **2D 也需测试**: `solve_probe3_2d`（包含圆形内嵌）

## 类别 A 小结

| WF ID | 验证重点 | 物理/数学核心 | 失败暗示 |
|---|---|---|---|
| WF-A1 | 通量BC → 线性温度场 | Neumann BC 实现 | 通量边界条件处理错误 |
| WF-A2 | 体积源 → 抛物线温度场 | Poisson 方程源项 | 体积功率累积错误 |
| WF-A3 | 接触热阻 → 温度跳跃 | 多材料界面耦合 | 接触面热阻参数传递错误 |
| WF-A6 | Robin BC + 体积源 | 对流边界与源项耦合 | Robin 边界或源项之一有误 |
| WF-A7 | 几何复杂度不引入伪影 | BVH 遍历正确性 | GPU 光追几何处理有误 |

**执行顺序**: WF-A1 → WF-A2 → WF-A6 → WF-A3 → WF-A7（从简到繁）
