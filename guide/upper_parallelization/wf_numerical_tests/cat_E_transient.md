# 类别 E：瞬态/非稳态实验原理

**关联清单**: [../numerical_correctness_test_checklist.md](../numerical_correctness_test_checklist.md)  
**GPU 测试 ID**: WF-E1, WF-E2, WF-E3, WF-E5  
**物理领域**: 瞬态热传导（热扩散方程）  
**共同容差**: `eq_eps(T.E, ref, 3 * T.SE)`（WF-E5 除外，使用 1% 温度范围）

---

## 物理总论

瞬态热传导方程：

$$\rho c_p \frac{\partial T}{\partial t} = \nabla \cdot (\lambda \nabla T) + P$$

引入热扩散率 $\alpha = \lambda / (\rho c_p)$ [m²/s]：

$$\frac{\partial T}{\partial t} = \alpha \nabla^2 T + \frac{P}{\rho c_p}$$

蒙特卡洛求解器对瞬态问题使用时间反向随机游走：从 $(x_0, t_0)$ 出发，布朗运动 + 扩散，直到撞击边界或时间回溯到 $t = 0$（初始条件）。

**瞬态 MC 的方差通常大于稳态**，因为路径更长、分支更多。因此瞬态测试允许适当放松容差（WF-E1 用 4σ + 90% 通过率，WF-E5 用 1% 固定容差）。

## WF-E1：3D 瞬态固体导热（对标 `test_sdis_unsteady`）

### 物理场景

单位缩放立方体（物理尺寸 0.01 m），6 面固定不同温度，初始均匀温度 $T_{init}$。

```
  几何坐标 (fp): (0,0,0) → (0.1, 0.1, 0.1)
  物理坐标 (m) : (0,0,0) → (0.01, 0.01, 0.01)   (FP_TO_METER = 0.1)
```

### 参数

| 参数 | 值 | 单位 |
|---|---|---|
| $T_{init}$ | 280 | K |
| $T_0$ (-X) | 310 | K |
| $T_1$ (+X) | 320 | K |
| $T_2$ (-Y) | 330 | K |
| $T_3$ (+Y) | 310 | K |
| $T_4$ (+Z) | 320 | K |
| $T_5$ (-Z) | 300 | K |
| $\lambda$ | 0.5 | W/(m·K) |
| $\rho$ | 2500 | kg/m³ |
| $c_p$ | 2000 | J/(kg·K) |
| $\delta$ | 1/60 ≈ 0.01667 | m |
| FP_TO_METER | 0.1 | — |
| $N$ | 10000 | — |

### 热扩散率

$$\alpha = \frac{\lambda}{\rho c_p} = \frac{0.5}{2500 \times 2000} = 1.0 \times 10^{-7} \text{ m}^2/\text{s}$$

特征扩散时间尺度 $\tau = L^2 / \alpha = 0.01^2 / 10^{-7} = 1000$ s。

### 硬编码参考值

观测点：fp 坐标 $(0.3, 0.4, 0.6)$ → 物理坐标 $(0.03, 0.04, 0.06)$ m

| # | 时间 [s] | 参考温度 [K] | 归一化时间 $t/\tau$ | 物理阶段 |
|---|---|---|---|---|
| 1 | 1,000 | 281.33455593977152 | 1.0 | 初始扩散 |
| 2 | 2,000 | 286.90151817350699 | 2.0 | 快速升温 |
| 3 | 3,000 | 292.84330866161531 | 3.0 | 中期升温 |
| 4 | 4,000 | 297.81444160746452 | 4.0 | 减速升温 |
| 5 | 5,000 | 301.70787295764546 | 5.0 | 接近稳态 |
| 6 | 10,000 | 310.78920179442139 | 10.0 | 趋于稳态 |
| 7 | 20,000 | 313.37629443163121 | 20.0 | 近稳态 |
| 8 | 30,000 | 313.51064004438581 | 30.0 | 近稳态 |
| 9 | 1,000,000 | 313.51797642855502 | 1000.0 | 完全稳态 |

### 参考值来源

这些参考值来自 **Green 函数级数展开**（3D 热传导的分离变量法解），每个方向贡献乘积形式的 Fourier 级数。CPU 测试用高精度预计算并硬编码。

### GPU Wavefront 适配

- **API**: `sdis_solve_wavefront_probe(pos={0.03, 0.04, 0.06}, time=t_i)` 对 9 个时间点
- **SPP**: 256
- **通过标准**: ≥90% 时间点在 4σ 内（瞬态方差大）
- **诊断**: 如果早期时间（$t < 3000$ s）通过但晚期不通过，可能是长时间路径的边界处理有问题

## WF-E2：1D 瞬态薄板导热（对标 `test_sdis_unsteady_1d`）

### 物理场景

2D 薄板内的严格 1D 瞬态扩散问题（Y 方向绝热）。这是最简单的瞬态解析解场景。

### 解析解

一维热传导方程在半无限/有限域上的经典 Green 函数解：

$$T(x, t) = \sum_{n=1}^{\infty} B_n \sin(k_n x) e^{-\alpha k_n^2 t} + T_{ss}(x)$$

其中 $T_{ss}(x)$ 是稳态解，$k_n = n\pi / L$，$B_n$ 由初始条件的 Fourier 展开确定。

### GPU Wavefront 适配

- **简化**: 严格 1D，方差低于 3D
- **SPP**: 256
- **通过标准**: ≥95% 在 3σ 内
- **价值**: 如果 WF-E1 (3D) 失败但 WF-E2 (1D) 通过，可定位问题在多维边界处理

## WF-E3：正弦衰减温度场（对标 `test_sdis_unsteady_analytic_profile`）

### 物理场景

精心构造的可分离变量解析解：空间初始分布为乘积正弦函数，时间演化为指数衰减。

### 解析解

$$T(x,y,z,t) = A \sin(k_x x) \sin(k_y y) \sin(k_z z) \cdot e^{-\alpha (k_x^2 + k_y^2 + k_z^2) t} + T_0$$

其中 $k_x = n_x \pi / L_x$, $k_y = n_y \pi / L_y$, $k_z = n_z \pi / L_z$。

### GPU Wavefront 适配

- **优势**: 完全解析解（非硬编码），可在任意 $(x,y,z,t)$ 计算参考值
- **SPP**: 512（需足够采样捕捉正弦空间变化）
- **通过标准**: ≥95% 在 3σ 内
- **正交相机**: 沿某轴渲染，像素值应呈正弦 × 指数衰减

## WF-E5：流体 + 固体 + 大气瞬态（对标 `test_sdis_unsteady_atm`）

### 物理场景

最复杂的瞬态场景：流体域 + 固体域 + 大气对流冷却 + 辐射。参考值来自高精度数值求解（非解析）。

### 参数

- 多域耦合：流体、固体、大气
- 容差：`eq_eps(T.E, ref, (Tmax - Tmin) * 0.01)`，即温度范围的 1%

### GPU Wavefront 适配

- **优先级**: P3（最复杂，非解析参考）
- **SPP**: 512
- **通过标准**: 1% 固定容差（沿用 CPU）
- **前置条件**: WF-E1/E2/E3 全部通过

## 类别 E 小结

| WF ID | 维度 | 参考来源 | 失败暗示 |
|---|---|---|---|
| WF-E1 | 3D | Green 函数硬编码 | 3D 瞬态路径追踪 / 时间积分错误 |
| WF-E2 | 1D | Green 函数解析 | 1D 瞬态基础有误 |
| WF-E3 | 2D/3D | 正弦分离变量 | 空间 Fourier 模式未正确捕捉 |
| WF-E5 | 多域 | 数值参考 | 多域耦合或大气模型有误 |

### 调试决策树

```
WF-E2 (1D) 通过?
  ├── 否 → 基础瞬态时间积分有问题
  └── 是 → WF-E1 (3D) 通过?
            ├── 否 → 多维边界处理有问题
            └── 是 → WF-E3 (正弦) 通过?
                      ├── 否 → 非均匀初始条件处理有问题
                      └── 是 → WF-E5 (多域) 通过?
                                ├── 否 → 多域耦合逻辑有问题
                                └── 是 → 瞬态物理完全验证 ✓
```

**执行顺序**: WF-E2 → WF-E1 → WF-E3 → WF-E5
