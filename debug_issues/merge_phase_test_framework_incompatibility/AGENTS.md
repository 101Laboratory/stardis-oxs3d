# Merge Phase 测试框架不兼容性问题

**问题类别**: 测试架构兼容性  
**优先级**: 低  
**状态**: 低优先级跟踪（2026-03-13 更新）  
**发现日期**: 2026-03-12  
**影响范围**: B4架构测试 + WF数值正确性测试  

## 问题概述

在 stardis-oxs3d-merge-phase 工作树中，原有的 B4 架构级测试和 WF 数值正确性测试无法正常编译。这阻碍了在新架构下进行测试验证和回归测试。

## 核心问题

### B4 系列测试（11个）
- **错误类型**: 编译错误 - 数据结构成员不存在
- **根因**: merge-phase 架构重构了 wavefront 相关数据结构
- **影响**: 所有架构级状态机测试无法编译

### WF 系列测试（22个）
- **错误类型**: 链接错误 - 函数未实现/导出
- **根因**: API 声明存在但函数体缺失
- **影响**: 数值正确性验证测试无法运行

## 当前状态

- ✅ B4 测试在 merge-phase 新架构下已不再作为必需测试项
- ✅ WF 测试虽改动量大，但关键数据已收集，可支撑当前问题判定
- ✅ 因此该问题降级为低优先级维护项，不阻塞当前主线

- ✅ 已完成详细编译审计
- ✅ 已创建专用 CMake 控制变量 `ENABLE_B4_WF_TESTS`
- ✅ 已识别具体的缺失成员和函数
- ⚠️ 后续仅在需要恢复全量回归测试链路时再推进修复策略
