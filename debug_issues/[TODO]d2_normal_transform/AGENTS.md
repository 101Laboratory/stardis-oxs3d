## 问题描述

cuBQL 和 oxs3d 后端使用不同的法线变换方法，在含非均匀缩放的场景下数学上不等价：

- **cuBQL**: 使用 `forward_transform` 3×3 旋转矩阵直接变换法线（非均匀缩放下**数学错误**）
- **oxs3d**: 使用 `optixTransformNormalFromObjectToWorldSpace()`（逆转置矩阵方法，**数学正确**）

**触发条件**：含非均匀缩放的 instance 变换（如 `scale(2,1,1)`）。  
**当前场景**：porous 等测试场景的所有 instance 变换均为纯旋转+平移（无缩放），两种方法产生相同结果，**无数值影响**。

---

## 修复方案

将 cuBQL 后端的法线变换改为逆转置矩阵方法，与 oxs3d 对齐：
- 对于含缩放的变换，需先求 3×3 仿射部分的逆矩阵，再转置后用于变换法线
- 或在场景数据中存储预计算的逆转置矩阵供 GPU shader 使用
