## 1. 验证方法与证明策略

### 1.1 蒙特卡洛 3σ 准则

STARDIS 求解器基于蒙特卡洛（MC）随机游走方法求解热传输方程。每个温度估计 $E$ 伴随标准误差 $\mathrm{SE}$，衡量统计不确定度。给定解析参考值 $T_\mathrm{ref}$，定义标准化偏差：

$$\sigma = \frac{|E - T_\mathrm{ref}|}{\mathrm{SE}}$$

若 MC 估计器无偏且服从正态分布，$\sigma$ 应服从半正态分布，99.7% 的样本满足 $\sigma \leq 3$。因此采用 **3σ 准则**作为通过判据。对于零方差情形（$\mathrm{SE} = 0$，如 $t = 0$ 时刻的初始条件精确注入），采用绝对误差 $|E - T_\mathrm{ref}| < 10^{-10}$ 判定。

### 1.2 物理复杂度阶梯

本报告以**物理输运过程的复杂度递进**为叙事主线，通过 5 张主力曲线图 + 1 张统计汇总图，完备证明 GPU wavefront（cuBQL 后端）与 CPU depth-first（Embree 后端）架构的数值一致性。

## 2. 稳态导热：体积功率倒抛物线 (图 1: A2)

> **对应图表**: [fig1_a2_parabola.png](img/fig1_a2_parabola.png)

### 2.1 物理模型

平板两面固定温度 $T_0 = 320$ K，体积内均匀热源功率 $P = 10$ W/m³，导热系数 $\lambda = 0.1$ W/(m·K)。稳态温度分布为 Poisson 方程 $\nabla^2 T = -P/\lambda$ 的一维特解：

$$T(x) = \frac{P}{2\lambda}\left(\frac{1}{4} - \left(x - \frac{1}{2}\right)^2\right) + T_0$$

这是经典的**对称倒抛物线**，中心温度最高 $T_\mathrm{max} = P/(8\lambda) + T_0 = 332.5$ K，两端等于边界温度 320 K。

图 1 主面板展示了 11 个 GPU（红色方块）和 11 个 CPU（蓝色圆点）数据点与解析倒抛物线（灰色虚线）的叠合。数据点在抛物线上均匀分布，3σ 误差棒清晰可见。

图 1 下方的 **σ 残差面板**显示所有数据点的 $\sigma = (E - T_\mathrm{ref})/\mathrm{SE}$ 分布。两种架构的残差均落在 $\pm 3$ 绿色区间内，且无系统性偏移趋势。GPU 在抛物线顶部（$x = 0.50$）处有最大偏移（$\sigma = 2.69$），仍在阈值内。

### 2.4 物理解读

- **对称性**：GPU 和 CPU 的温度分布均精确反映了 $x = 0.5$ 的对称轴——左右各 5 点基本对称。
- **边界处方差小**：$x = 0.05$ 和 $x = 0.95$ 处的 SE 最小（~0.06 K），因为靠近 Dirichlet 边界的 MC 路径短。
- **中心处方差大**：$x = 0.50$ 处 SE 最大（~0.10 K），因为 MC 路径需要扩散到边界才能终止。

**结论**：在最基础的 Poisson 方程稳态导热场景中，GPU 和 CPU 均精确复现了倒抛物线解析解，且统计行为一致。

## 3. 多材料界面：接触热阻折线族 (图 2: A3)

> **对应图表**: [fig2_a3_contact_resistance.png](img/fig2_a3_contact_resistance.png)

### 3.1 物理模型

两种不同导热系数的材料（$\lambda_1 = 0.1$, $\lambda_2 = 0.2$ W/(m·K)）拼接于 $x_0 = 3$ m 处，总长 $L = 4$ m。左端 $T_0 = 0$ K，右端 $T_L = 100$ K。界面处有接触热阻 $R$ [m²·K/W]。

稳态热流密度：
$$q = \frac{T_L - T_0}{x_0/\lambda_1 + R + (L - x_0)/\lambda_2}$$

温度分布：
- 左侧 ($0 \le x \le x_0$): $T(x) = T_0 + (q/\lambda_1)\,x$ — 线性升温
- 右侧 ($x_0 \le x \le L$): $T(x) = T_L - (q/\lambda_2)(L - x)$ — 线性升温
- 界面处温度跳跃: $\Delta T = q \cdot R$

5 个 $R$ 值（0.01, 0.1, 1, 10, 100）形成一个**扇形展开的分段线性折线族**：$R$ 越大，穿过界面的热流越小，界面温度跳跃越大，曲线越平缓。

| R 值范围 | {0.01, 0.1, 1, 10, 100} | {0.02 – 88}（连续随机谱） |

### 3.3 结果

| 指标 | GPU wavefront | CPU depth-first |

| σ 均值 | 0.748 | 0.950 |
| σ 最大值 | 2.334 | 2.067 |

图 2 展示了 5 条解析折线（viridis 渐变色），在 $x = 3$ 处均有清晰的温度跳跃（灰色竖虚线标注 "Interface"）。GPU 40 个红色方块整齐排列于各自对应的解析折线上；CPU 16 个蓝色圆点以随机 R 值和随机空间坐标散布于折线族上下文中。

**关键观察**：

- **R = 0.01（最小热阻）**：界面几乎连续，温度场近似线性。GPU 8 点 σ 均值 0.56。
- **R = 100（最大热阻）**：界面跳跃约 95 K，左侧几乎等温（< 4 K），右侧急剧上升。GPU 8 点 σ 均值 0.59。
- **CPU 随机探针**：覆盖了从 R = 0.02 到 R = 88 的连续谱，所有点均在对应折线的 3σ 范围内。

**结论**：GPU 和 CPU 均在多材料异质性 + 界面物理的场景中给出正确结果。GPU 的 5 组 R 参数系统扫描 + CPU 的随机 R 采样，从两个互补角度验证了接触热阻求解的正确性。

## 4. 对流换热瞬态：指数衰减 (图 3: D1)

> **对应图表**: [fig3_d1_convection.png](img/fig3_d1_convection.png)

### 4.1 物理模型

立方体固体初始温度 $T_0 = 280$ K，六面暴露于均匀流体温度 $T_\infty = 325$ K，对流换热系数 $H$。集总参数模型（Biot 数 ≪ 1）给出精确的指数趋近解：

$$T(t) = T_0 \, e^{-\nu t} + T_\infty \left(1 - e^{-\nu t}\right)$$

其中衰减率 $\nu = 6H/(\rho c_p) = 1.2$ s⁻¹（六面均匀对流）。这是**牛顿冷却定律最直观的时域表现**——温度从 280 K 指数升温，渐近趋于 325 K。时间常数 $\tau = 1/\nu \approx 0.83$ s。

## 5. 扩散方程精确解：sin × exp (图 4: E3)

> **对应图表**: [fig4_e3_sin_exp.png](img/fig4_e3_sin_exp.png)

### 5.1 物理模型

本测试采用**制造解法**（Method of Manufactured Solutions, MMS）：预先构造一个扩散方程的解析解，将其在封闭几何体表面的值作为 Dirichlet 边界条件施加，然后由 MC 求解器从边界数据反算内部温度场，最后与预设的解析解比对。

**几何体**为超形体（supershape，由超公式曲面定义，参数 $M = 11$, $N_0 = 1$ 等），而非简单的立方体。MMS 的关键在于：每个边界面元 $\mathbf{P}$ 在时刻 $t$ 的温度等于解析解在该处的值 $T(\mathbf{P}, t)$（非常数温度）。固体内部温度设为未知（`SDIS_TEMPERATURE_NONE`），初始时刻 $t_0 = -\infty$（无初始条件，完全由边界驱动）。

预设的解析温度场为：

$$T(x,y,z,t) = \frac{1}{\lambda}\left[B_1(x^3 z - 3xy^2 z) + B_2 \sin\frac{\pi}{4}x \, \sin\frac{\pi}{4}y \, \sin\frac{\pi}{4}z \cdot e^{-\alpha k^2 t}\right]$$

其中 $B_1 = 10$, $B_2 = 1000$, $\alpha = \lambda/(\rho c_p) = 0.002$ m²/s, $k^2 = 3(\pi/4)^2$, 时间常数 $\tau = 1/(\alpha k^2) \approx 270$ s。

这一解析解**刻意构造**为两个分量的叠加：
- **多项式稳态项** $B_1(x^3z - 3xy^2z)/\lambda$：满足 Laplace 方程的调和多项式，在任意几何体上均可自洽。
- **正弦瞬态项** $B_2 \sin(k_x x)\sin(k_y y)\sin(k_z z) \cdot e^{-\alpha k^2 t}/\lambda$：扩散方程的本征模式，振幅以 $\tau = 270$ s 指数衰减。

正弦成分并非源于恒温边界或几何对称性，而是被选定的制造解本身的特征——只要边界温度严格等于解析值，MC 在内部任意点的估计就应恢复出该解。

图 4 以**双子图**展示：

- **左图**：固定空间点 $(0.2, 0.3, 0.4)$，温度随时间的指数衰减（对数时间轴，0.3–1500 s）
- **右图**：固定时刻 $t = 5$ s，温度沿 $x$ 轴的正弦空间分布

#### 5.3.1 时间衰减（左图）

对数时间轴清晰展示了从 $T \approx 111$ K（$t = 0.5$ s）到 $T \approx 1$ K（$t = 1000$ s）的完整指数衰减过程。绿色竖虚线标注了时间常数 $\tau = 270$ s 的位置——在此之前衰减缓慢（稳态多项式项 ~0.6 K 相对于 ~110 K 的正弦瞬态项可忽略），在 $\tau$ 附近进入快速衰减段，远超 $\tau$ 后趋近稳态值 $T_\mathrm{ss} \approx 0.6$ K。

GPU 和 CPU 的 13 个数据点均精确落在解析曲线上。残差面板显示 GPU 的 σ 值随时间略有增大（~0.3 at $t = 0.5$ s → ~2.7 at $t = 1000$ s），与 MC 方差在长时间积分下积累的物理预期一致。CPU 侧 σ 值极小（< 0.16），统计精度更高。

### 5.4 物理解读

E3 是最完整的 PDE 解析解验证——它同时检验：
1. **空间导数**的正确离散（正弦分布）
2. **时间积分**的正确实现（指数衰减）
3. **非线性温度场**的正确求解（稳态多项式 + 瞬态正弦的叠加）
4. **长时间精度**（从 $t = 0.5$ s 到 $t = 1000$ s，跨越近 4 个 $\tau$）

**结论**：GPU 和 CPU 均精确复现了扩散方程的完整 $\sin \times \exp$ 解析解，验证了时空两个维度上的数值一致性。

## 6. 多域耦合瞬态：流体–固体–大气 (图 5: E5)

> **对应图表**: [fig5_e5_multidomain.png](img/fig5_e5_multidomain.png)

### 6.1 物理模型

流体域 + 固体域 + 大气层的多介质耦合系统，从均匀初温 300 K 开始的瞬态热响应。辐射边界条件驱动能量输入。参考值来自高精度数值求解（非封闭解析式，硬编码）。

- **流体探针** $(1.5, 1.5, 1.5)$：位于流体域中心，接近辐射边界，升温快。
- **固体探针** $(3.04, \cdot, \cdot)$：位于固体域内，热惯性大，升温慢。

形成经典的**"快/慢趋近"双时间尺度对比**——流体约 3000 s 达稳态（~310 K），固体超过 10000 s 仍在缓慢爬升（~305 K）。

- $t = 2000$ s 时 GPU σ = 2.07（最大值），但趋势严格跟踪参考曲线。
- 固体的 SE 从 ~0.028 K（$t = 1000$ s）增长至 ~0.056 K（$t = 9000$ s），反映了瞬态 Green 函数积分域随时间扩大导致的方差增长——两种架构显示完全相同的方差增长趋势。

σ 残差面板显示所有数据点均在 ±3 区间内，无系统性偏移。

### 6.4 物理解读

E5 是最接近工业真实场景的测试——它同时检验：
1. **多域耦合**：流体↔固体↔大气的能量交换
2. **辐射边界条件**：大气层的辐射热传递
3. **长时间瞬态**：0 → 10000 s，跨越多个特征时间尺度
4. **双时间尺度**：流体快响应 vs 固体慢响应

**结论**：GPU 和 CPU 在最复杂的多域耦合瞬态场景中给出完全一致的温度演化，包括流体快响应和固体慢响应的双时间尺度特征。

## 8. 已知缺陷与局限

### 8.1 I1 — 嵌套包壳体积功率（已澄清）

GPU I1 测试在早期分析中呈现两个表面上的严重偏离（$\sigma = 6.1$ 和 $10.9$）。经独立分析确认，**根本原因为参考值选取错误**——sub_id 编码映射与 CPU 侧不一致，导致 GPU 估计值与错误的解析参考值进行了比对。

使用正确的参考值后，I1 的 2 个 GPU 数据点均通过 3σ 检验。此问题不涉及 OptiX 后端的几何处理或算法正确性。

**处置**：I1 已从"已知缺陷"降级为"已澄清的数据映射问题"。全部 13 个测试（134 个 GPU 数据点）均通过 3σ 检验。

### 8.2 方差结构一致性
